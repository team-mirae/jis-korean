# engine

Core engine of JIS Korean: key map, Hangul automaton, commit logic, F6–F10 and hanja. No OS APIs,
no I/O. See [../docs/spec.md](../docs/spec.md).

| Path | What |
|---|---|
| `src/` | The engine. `ffi.rs` is the C ABI in `include/jis_korean.h`. |
| `dict/hanja.tsv` | Hanja dictionary (generated by `dict/build_dict.py`; licenses alongside). |
| `tests/golden.rs`, `tests/hanja.rs` | Key sequences → expected text, for every spec example. |
| `src/predict.rs`, `predict/` | The optional predictive layer (spec §10, `predict` feature): ranks Korean, English and other readings of the staged text. `predict/` holds its model and word lists. |
| `src/plan.rs` | The typing robot and key-press counts (JIS Korean vs conventional 2-set), used by the robot test and the web playground. |
| `tests/robot.rs` | The robot types a real document key by key; see the report with `--nocapture`. |
| `tests/data/fetch_corpus.py` | Fetches the robot's corpus (gitignored). |

```sh
cargo test
cargo test --no-default-features      # the lite engine, without prediction
cargo test --test robot -- --nocapture
python3 -I tests/data/fetch_corpus.py   # from tests/data
```
