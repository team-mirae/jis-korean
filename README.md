# JIS Korean

A Korean 2-set (두벌식) input method for JIS keyboards, for macOS, Windows and the web.

- Spec: [docs/spec.md](docs/spec.md)
- `engine/`: core engine (shared by all platforms)
- `mac/`: macOS input method
- `windows/`: Windows input method (TSF)
- `android/`, `ios/`: mobile input methods (planned)
- `web/`: browser playground
