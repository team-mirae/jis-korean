# Easy key sequences that type Korean words

Short runs of keys on the number row (JIS Korean's dedicated keys) and the home row that type real words, thanks to the dedicated keys and the implied ㅇ: `98` is 의외, `09` is 와의, `675` is 위웠. Keys are the letters and digits on the keys, no Shift. A word counts when the corpus lexicon has seen it at least 20 times or it's in the hanja dictionary (marked *dictionary*). **Top** is whether it's the top prediction when typed alone. Travel is finger travel in key widths (`engine/src/travel.rs`).

Pieces of words count only when they're words themselves: `675` types 위웠 (as in the end of 무서웠, 어려웠), which isn't one, so it isn't listed. Each word appears once, with its easiest route.

Generated by `cargo run --release --example easy` in `/engine`; don't edit by hand.
