JIS Korean on an 87-key board

Mode A, JIS Korean's original layout, on an ANSI tenkeyless board remapped as a JIS board: カタカナ, 英数 and かな on the thumbs, and ¥, ろ and the F18 Korean Key on the Fn layer. The keys reach macOS through Karabiner-Elements' JIS virtual keyboard (README.md). Reference board: MONGDOL 87 BT-1.

カタカナ · 英数 · かな
Bottom-left goes to Korean, left of Space to English, right of Space to Japanese. Each key always goes the same way. Held, the first two are Fn and ⌘.
The caps move by one
JIS has @ [ ] where ANSI has [ ] \, so the ANSI [ ] \ type Mode A's ' " · [ 「 · ] 」, and ' types JIS's : key.
Number row
Double consonants and compound vowels, digits on Shift, as on JIS. - and = are JIS's − and ^: ! ? and ( ).
F6–F10
한글, 한자, 두벌식, 전각 and 반각, on the plain F-keys. Shift+Z is F10 too.
Not on this layer
¥ and ろ, which an ANSI board has no key for: they're on the Fn layer. ` isn't a JIS key and types ` and ~.
Moved keys
Ctrl is on Caps Lock, HHKB-style; swap it with the bottom-left key if you'd rather have Ctrl there. Caps Lock is on Scroll Lock. Print Screen is ⌘⇧4 and Pause is Play/Pause: the board's own extras.
Layer 2

Fn layer

Hold the bottom-left key or the rightmost bottom key
JIS keys in Mode A F13–F24 Korean Key (F18) and Fn The board's own (media, mouse, lighting)
Fn+F6 is F18
JIS Korean's default Korean Key: it goes to Korean like カタカナ, from any input source, whatever macOS thinks the keyboard is.
¥ and ろ
Right of Space: ¥ (— and ^ in Mode A), / (·, as on the plain / key) and ろ (\ and _). In Japanese Kana they're ー, め and ろ.
F13–F24
On F1–F12. Only F18 is JIS Korean's; the others are free for shortcuts.
